Template Overleaf — Cálculo Numérico (UNIFESP)

Como usar:
1. Crie um projeto em branco no Overleaf.
2. Envie main.tex e referencias.bib.
3. Se inserir figuras, envie também os arquivos e atualize os nomes no main.tex.
4. Compile com pdfLaTeX.
5. Substitua os textos de orientação, exemplos e dados pelos conteúdos do seu trabalho.
6. Disponibilize códigos, dados e instruções de execução em um repositório (por exemplo, GitHub), com README.md.

A estrutura contempla introdução, objetivos, fundamentação teórica, descrição do método,
implementação computacional, experimentos numéricos, resultados, análise, conclusões,
referências e apêndices.
